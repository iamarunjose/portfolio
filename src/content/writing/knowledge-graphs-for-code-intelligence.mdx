## 1. Why Flat Text Chunking Fails on Codebases

Standard vector retrieval treats source code as contiguous blocks of prose. While effective for surface-level snippet lookup, flat chunking loses the explicit structural topology that defines software behavior: imports, interface implementations, type hierarchies, and cross-module call chains.

## 2. The Code Property Graph Approach

By parsing source repositories into a unified **Code Knowledge Graph**, every symbol, module, configuration key, and test case becomes a first-class typed node connected by explicit semantic edges:

- `DEFINES_SYMBOL` / `EXPORTS_INTERFACE`
- `CALLS_FUNCTION` / `READS_CONFIG`
- `COVERED_BY_TEST` / `MODIFIED_IN_COMMIT`

// Conceptual Graph Query for Blast-Radius Analysis

  verifyTestCoverage: boolean;
}
