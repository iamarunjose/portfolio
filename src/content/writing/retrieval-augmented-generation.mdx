## 1. The Precision Gap in Standard RAG

In technical and regulatory domains—such as export control classification or engineering specification verification—relevant evidence rarely lives in a single isolated paragraph. Answering a query accurately requires following hierarchical rules, cross-references, and domain definitions simultaneously.

## 2. Hybrid Retrieval Architecture

A **Hybrid Semantic Framework** addresses this limitation by orchestrating three complementary retrieval channels:

1. **Dense Vector Retrieval**: Capturing conceptual similarity across varied technical phrasing.
2. **Sparse Lexical Matching**: Preserving exact identifier, part-number, and regulatory code matches.
3. **Knowledge Graph Traversal**: Expanding retrieved anchors along explicit taxonomic and relational edges.

```text
[User Query]
     │
     ├──► Dense Vector Index (Semantic Recall) ──┐
     ├──► Lexical Index (Exact Term Precision) ──┼──► [Rank Fusion & Subgraph Verifier] ──► [Grounded Synthesis]
     └──► Knowledge Graph (Multi-Hop Rules)   ──┘
```
